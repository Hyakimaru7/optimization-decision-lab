# 固定方案的有效范围

[English](../plan-validity.md) | **简体中文**

用于方案执行前复核、输入更新、计划交接和缓冲比较。它回答“原动作还满足声明的约束吗”，不回答“重新求解能否获得更好动作”。这与 LP 最优基敏感性分析不同。

## 可运行范围

```bash
python3 scripts/assess_plan_validity.py assets/plan-validity-example.json
```

脚本适用于固定 LP/MILP 数值解，支持线性不等式、等式、变量上下界与原整数域。整数性不会因本工具的参数盒变化而改变；不支持变量域变化、逻辑/非线性约束、相关不确定集或观察后的补救策略。其他模型应使用原业务回验、结构相符的方法或仿真，并明确保证范围。

对 `a_i x <= b_i`，给定逐系数绝对变化界 `d_ij`、右端绝对变化界 `e_i`，独立盒内允许同时取最坏值：

`worst_residual_i(rho) = a_i x - b_i + rho * (sum_j(abs(x_j)*d_ij) + e_i)`。

这是固定 x 下该盒内的最坏残差。等式使用 `abs(a_i x-b_i) + rho*growth`；下界取最坏增加，上界取最坏减少。各行有效半径由 `(threshold-nominal_residual)/growth` 得出，总半径取最小值。盒表示独立变化的包络，即使真实变化相关，它也可能过于保守；不是概率置信区间。

原方案不满足容差时不返回有效半径；某行增长为零且原本通过时，该行在声明盒中不限制半径。所有增长为零时返回 `max_radius:null` 加 `unbounded_in_declared_box:true`，不表示现实中永久有效。等式通常对独立扰动非常脆弱，这个结论不能靠改成不等式隐藏。

浮点检查使用明确容差，不是有理数精确证明或区间算术证明。容差固定在原模型尺度，不能随扰动扩大而隐式放宽。实际硬物理限制可设零容差，但仍须注意浮点计算误差；需要严格数学认证时改用精确或可靠区间工具。

## 输入契约

顶层均必填，未知字段拒绝：

- `model`：原线性检查器的输入，必须有实际 `solution`；格式见 [求解与认证](solver-validation.md#线性解检查器)。
- `uncertainty.inequalities` 与 `.equalities`：各含 `coefficient_absolute` 矩阵、`rhs_absolute` 数组，与对应模型逐行同维度；没有行也写空数组。所有数值非负。
- `uncertainty.bounds`：每变量 `[lower_absolute,upper_absolute]`，未设置的界必须对应零变化。
- `target_radius`：非负倍数。`rho=1` 表示原先声明的整套变化界。各变化界应有数据、工程范围或明确假设，不自动拟合。
- `tolerances`：`atol,rtol,integer_tol` 均非负；每行单位不同可用原模型的 `scales`。说明取值依据。
- `artifact`：`model_revision,data_revision,context_revision,generated_at,expires_at`。
- `current`：同三种版本和 `as_of`。时间为带时区的 ISO 8601，`expires_at > generated_at`。有效期由业务选择，不给通用小时数。

零变化界明确表示本次分析把该项固定，不能作为“尚不知道误差”的代号。目标、规则、变量域和未列机制不在盒保证中。业务语境版本至少涵盖订单、人员资格、执行地点、已承诺动作等实际适用内容；内容哈希应由调用者真实生成。

三种版本有任一不一致、到达失效时间、生成时间在未来、原方案无效或目标半径越界均返回 `review_required`。即使数值包络通过，版本变化仍需要核查：先重建原约束和已承诺状态，再出新的输入/结果记录。这不表示新状态一定无解。工具只比较传入字符串与时间，不读取业务系统、不核验哈希来源、不自动重新求解或执行动作。

退出码 0：当前快照一致且在声明包络内；1：需要核查；2：输入错误。报告保留每个限制行及原因，最优性始终未认证。不要将退出码 0 等同于获得业务执行授权。

## 决定是否重规划

硬约束变得不满足时先处理可行性，切换费用不能成为忽略违约的依据。可行时比较新方案收益、取消/切换代价及计算开销；也可在原目标有有效界时先判断是否值得继续求解。

最大化模型当前可行值为 L、有效上界为 U。若所有可接受替换的切换成本至少为 K，且 `U-L <= K`，则在这些假设下替换不会获得严格正净收益。界须属于当前模型、当前数据与同一收益口径；若 K 只是典型值而非有效下界，不能作这一结论。最小化时用当前成本减有效下界。均不自动证明当前方案最优。
