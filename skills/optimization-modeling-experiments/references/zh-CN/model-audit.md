# 模型审查与重构

[English](../model-audit.md) | **简体中文**

在建立、审查或重构优化模型时按相关部分读取。

## 语义、数据与边界

以“实际需求 → 数学表达 → 代码位置 → 回验函数”建立对应关系。先分清决策与已知参数：未来随机需求不是可预知的确定参数；情景决策要满足其决策时点的信息结构。

检查：
- 各索引集合是否一致，是否出现漏项、重复项或非法组合。
- 数量、时间、成本、概率是否量纲一致；平方损失和绝对损失是否采用明确尺度。
- 容量、需求、概率、协方差和距离等数据是否满足定义域条件。
- 缺失值与异常值如何处理；不静默改写原始数据。
- 边界变量、空集合、零容量、零需求、初末状态和极端参数是否有清晰含义。

变量声明明确实数/非负/整数/二元及上下界。不要因为求解器默认非负而漏写自由变量，不要因忽略变量属性而漏验隐式约束。

## 可行性、有界性与存在性

可行性分析应包括易检查的必要条件、已知可行构造或小实例求解。必要条件通过不证明充分性。

连续模型在非空紧可行集上且目标连续时可保证最优解存在；非空闭集与目标在可行集上的适当强制性也是可用的充分条件。说明所用条件，不用“有下界”替代“能达到最优值”。严格凸性只有在凸可行集等适当条件下提供唯一性，且仍需解存在。

无界与不可行分开诊断。可沿疑似可行方向检查目标是否持续改善；局部求解器失败本身不证明不可行或无界。

## 凸性与问题类别

标准凸最小化需要凸目标、凸不等式函数、仿射等式及凸变量域。目标最大化时对应凹目标。整数域整体非凸，即使其连续松弛为凸。

二次形式检查对称部分及半正定性；数值特征值近零时说明误差尺度。凸函数的等式约束一般不是凸约束。工具的 DCP 规则是可识别凸性的规则体系，不是所有凸表达的完整判定器。

## 常见重构

| 操作 | 所需核查 | 不应省略的解释 |
| --- | --- | --- |
| epigraph：以 t≥f(x) 替代目标项 | 目标对 t 的方向/单调性，其他 t 约束 | 在何种条件下 t 会取紧 |
| 绝对值/最大值引入辅助变量 | 是否确实在最小化相应上界 | 上图形式不能任意替代等式或非凸下界 |
| Big-M / indicator | 有效变量界和对应逻辑方向 | M 太小会删去可行解，过大会恶化松弛与数值条件 |
| 二元变量与连续变量乘积 | 连续变量有效上下界 | 完整线性化约束及解恢复 |
| 连续双线性项的 McCormick 包络 | 有界矩形定义域 | 一般是松弛，不是乘积等式的精确替代 |
| 分式变量替换 | 分母符号、零点、可逆性 | 新域、目标映射和恢复条件 |
| 整数连续松弛 | 原整数域与松弛域 | 舍入不自动保留约束，需修复并回验 |
| 罚函数/软约束 | 原硬约束、罚系数与尺度 | 不是默认等价；是否允许违反需来自任务授权 |
| 平滑/离散化 | 参数、误差与网格 | 有近似偏差，应进行精度或网格敏感性验证 |

对最小化，扩大可行域且保持目标可产生下界；缩小可行域可产生上界，但只有存在可行解时才提供可用候选。最大化时方向相反。修改目标的重构不能仅根据可行域包含关系判断界，需要相应目标关系。

## 多目标、随机与鲁棒建模

加权和注明目标单位、归一化和权重含义。在非凸目标像中，加权和一般不能恢复全部 Pareto 点；使用 ε-约束等方法时说明约束阈值及可行性。

场景概率非负且归一化；概率归一化的修改留痕。区分期望、风险度量、机会约束和最坏情形目标。有限场景可行不自动保证总体机会约束。

鲁棒模型明确不确定集、信息结构、对偶化条件和保守性；情景近似不自动等价于对整个不确定集的保证。

随机/预测模型的训练、调参和最终评估数据分开。拟合归一化、需求分布或不确定集时避免使用测试集信息。

双层模型转单层时核查内层最优性表征、约束资格、强对偶和内层解选择；局部 KKT 条件不能一般性替代全局内层最优性。

## 模型审查交付

列出问题位置、受影响结论、证据及最小修正。审查报告区别确定错误、条件不足与待用户确认的语义。保留原模型和修正模型的可追溯关系。
