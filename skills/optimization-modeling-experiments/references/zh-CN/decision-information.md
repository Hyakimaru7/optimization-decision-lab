# 选择能改变决策的测量与实验

[English](../decision-information.md) | **简体中文**

用于缺少参数、考虑购买传感器/测量数据、选择科研区分实验或决定何时停止收集。重点是决策收益，不把信息增益或预测精度提升自动等同于应用价值。

## 明确先后顺序

列出待选行动、未知状态、同一单位的损失、当前可见信息、观测机制、测量成本/延迟及行动截止时间。区别未来随机事件与当前未知参数；测量必须有机会在决策前改变行动。已承诺不可修改的动作没有事后选择收益。

有可信概率与损失时用预期信息价值；未知分布时用参数范围、决策切换边界、情景后悔或最小区分实验。不要用任意权重得到的期望收益宣称测量必然回本，也不要仅因为某参数方差最大就优先测它。

## 有限表计算

```bash
python3 scripts/evaluate_information.py assets/information-example.json
```

所有行动必须在所有列出的状态下可行；否则将明确的补救成本和可行补救政策建成行动，或使用适配的两阶段模型。本脚本拒绝 `actions_feasible_in_all_states` 不为 `true` 的输入。该布尔值是调用者声明，须独立验证，不能用大额有限罚款吞掉硬违约。

对于损失表 L(a,theta) 和权重 p(theta)：

- 不观测的最优预期损失 `C0 = min_a sum_theta p(theta)*L(a,theta)`。
- 理想完全信息损失 `CPI = sum_theta p(theta)*min_a L(a,theta)`；`EVPI=C0-CPI`。它是同一行动集内的理想信息价值，不代表可购买真实测量。
- 实验 e 有信号 z 和条件概率 `q(z|theta,e)`。观测后最优预期损失 `Ce = sum_z min_a sum_theta p(theta)*q(z|theta,e)*L(a,theta)`。
- `EVSI=C0-Ce`；净价值为 `EVSI-实验成本`。在此完整表及风险中性假设下应有 `0<=EVSI<=EVPI`（浮点误差除外）。
- 每个行动的最坏后悔 `max_theta[L(a,theta)-min_b L(b,theta)]`；选择最小者是该声明情景集上的 minimax regret。它不是最坏损失最小，也不证明集合外可靠性。

顶层必填：`distribution_kind`（`hypothetical/empirical/calibrated`）、`loss_unit`、上述可行声明、非空 `states`、对应 `probabilities`、非空 `actions`、按行动行/状态列的 `losses`、`experiments`。ID 不重复，数值有限；支持负损失。概率非负且和为 1（仅容许 1e-9 舍入误差）。

每个实验含 `id,signals,likelihood,cost,available_before_decision`；`likelihood` 按状态行/信号列，每行概率和为 1；成本非负、单位与损失一致；时序声明必须为 true。完整示例见资产 JSON。零概率信号不指定行动；预期损失忽略零概率状态，而最坏后悔包含所有声明状态。相同最优值时按输入行动顺序选择代表项，不声称唯一性。

脚本不拟合似然、生成实验数据或认证概率校准；退出码 0 表示表已计算，2 表示输入无效。收益、概率与模型失配仍需现场数据检验；`calibration_verified/population_guarantee` 永远为 false。多次测量组合不能简单相加单次 EVSI，因为信息重叠且后续测量可依先前观测改变。

## 从表到现场/科研

明确测量改变哪项行动，再设计能分辨相关状态且来得及影响决策的试验。记录原策略、测量策略、付出成本、延迟影响、观测质量及执行后统一损失。先用小规模或影子回放检验，真实试点按用户授权进行。

科研问题若还没有可辩护的应用损失，可先提出可证伪的区分实验：两个竞争机制在哪些设置下预测不同、可观察什么、噪声多大、什么结果会否定各机制。未知参数结构不可识别时先改变实验设计，增加同类重复不能凭空解决结构不可识别。

有依据的 EVPI 可作为继续采集信息的成本上界；若最便宜的可用信息成本已超过它，可在同一决策/行动集/期限下停止。不能据此停止以建立新机制、新行动或长期科学知识为目标的科研。
